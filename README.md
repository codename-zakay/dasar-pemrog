# Machine Learning 
machine learning yang kita pakai disini, masih awam ya puh. disini kita pakai Framework Tensorflow
dengan beberapa Library tambahan seperti Keras, Matplotlib, dan Numpy

## Tensorflow Installation
kalian bisa liat di websitenya [Tensorflow](https://www.tensorflow.org/)
atau ikuti langkah berikut

bikin environment baru
```bash
    python3 -m venv tf-env
    source tf-env/bin/activate
```
sebelum lanjut ke langkah berikutnya, masuk dulu kedalam directory folder kalian. lalu lanjut ke langkah berikutnya

Upgrade PIP (opsional, tapi kalau bisa upgrade dulu)
```bash
    pip install --upgrade pip
```

Lalu install Tensorflow
```bash
    pip install tensorflow
```

Kalau kalian pakai GPU Nvidia, kalian bisa install juga command dibawah
ini agar Proses Tensorflow semakin cepat
```bash
    pip install tensorflow[and-cuda]
```

Setelah itu kalian bisa download Library untuk framework Tensorflow
```bash
    pip install numpy keras matplotlib
```
